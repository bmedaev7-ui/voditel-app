# Курьер-Бизнес — приложение водителя

Готовый проект для Vercel. Внутри:
- `index.html` — интерфейс водителя;
- `api/route.js` — серверная функция для 2ГИС;
- `vercel.json` — настройки функции;
- `manifest.webmanifest`, `sw.js`, `icon.svg` — установка на главный экран и базовый офлайн-кэш.

## Что уже реализовано

- поездка: адреса отправления и назначения;
- маршрут на автомобиле через 2ГИС;
- расстояние и примерное время;
- расчёт тарифа:
  - до 3 км — 250 ₽
  - до 5 км — 300 ₽
  - до 8 км — 350 ₽
  - до 12 км — 400 ₽
  - до 15 км — 500 ₽
  - до 20 км — 600 ₽
  - до 25 км — 700 ₽
  - до 30 км — 800 ₽
  - больше 30 км — цена вводится вручную;
- история поездок;
- доход за день, неделю и месяц;
- начало и завершение смены;
- профиль водителя;
- экспорт и восстановление резервной копии.

## Важно о данных

Данные поездок и профиля хранятся в `localStorage` текущего браузера. Это не облачная база: данные не синхронизируются между телефонами. Для переноса используй «Скачать копию» в профиле. Не очищай данные браузера без резервной копии.

## Установка в существующий GitHub-репозиторий

1. Скачай архив и распакуй его.
2. В репозитории `bmedaev7-ui/voditel-app` замени `index.html` новым.
3. Создай папку `api`, если её нет, и положи туда `route.js`.
4. Добавь в корень `vercel.json`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
5. Зафиксируй изменения в ветке `main`.
6. В Vercel у проекта `voditel-app` должна быть переменная окружения `DGIS_API_KEY` со значением твоего ключа 2ГИС. Секрет не добавляй в GitHub и не присылай в чат.
7. После изменения переменной окружения или кода дождись нового Production Deployment со статусом Ready.

## Проверка API

После успешного развёртывания открой:
`https://ТВОЙ-ДОМЕН.vercel.app/api/route`

При GET-запросе должно вернуться JSON:
`{"ok":true,"service":"voditel-api","message":"API работает"}`

Если вместо этого 404, функция не опубликована или Vercel использует другую корневую папку/проект. Если JSON сообщает, что не задан `DGIS_API_KEY`, добавь переменную в Settings → Environment Variables и заново разверни Production.

## Настройки ключа 2ГИС

Функция отправляет запросы с Referer, равным адресу сайта Vercel (например, `https://voditel-app.vercel.app/`). Если у ключа 2ГИС включено ограничение по Referer, разреши домен сайта Vercel в настройках ключа. Не публикуй ключ в клиентском HTML.

## Проверенные официальные спецификации

- Vercel: функции Node.js в корневой папке `api/` и Web Standard export: https://vercel.com/docs/functions/runtimes/node-js
- 2ГИС Geocoder: https://docs.2gis.com/api/search/geocoder/overview
- 2ГИС Routing: https://docs.2gis.com/api/navigation/routing/examples/routing

## Ограничения

- Демо-ключ 2ГИС имеет ограничение максимальной длины маршрута 50 км согласно документации 2ГИС.
- Приложение считает по сохранённой тарифной сетке, которую можно изменить в `index.html` в массиве `TARIFFS` и блоке «Тарифы».
- Время в маршруте — оценка 2ГИС, а не гарантия фактического времени в пути.
- Проект подготовлен для развёртывания; доступ к аккаунтам пользователя и публикация от его имени не выполняются автоматически.
